- **2026-11-18** (#389) — P14.25 now reads the `packageManager` pin from the
  directory selected by `npm ci` / `npm install --prefix`, `pnpm -C` /
  `pnpm --dir`, and `yarn --cwd`. Static paths compose with the step's current
  directory; paths that would leave the checkout fall back to the repository
  root pin instead of reading an outside manifest.
- **2026-11-21** (#389) — A directory option leaves two pins that can pick the
  version: Corepack resolves it from the launch directory, while a standalone
  pnpm 10 switches to the target's pin. A pnpm `-C` / `--dir` install is
  treated as covered by the pnpm-10 build-allowlist disable only when both
  pins resolve pnpm 10 or later (a root pinned at pnpm 9 no longer borrows a
  nested pnpm-10 pin's cover), and the condition note names the launch
  directory's pin when the two differ and both name the install's manager.
